1. Browser & USB prerequisites

Checking browser WebUSB and Chromium support…

  • Use a current Chromium, Chrome, Edge, or Brave window — not Firefox or Safari for live USB.
  • Private / Incognito windows are not a supported path. Origin storage in those windows is too small to hold the real artifacts.

Install Android udev rules (android-udev-rules) and stop fwupd if it claims the fastboot interface: sudo systemctl stop fwupd.service. Also stop any local adb daemon: adb kill-server.

No extra kernel driver is required on macOS. Stop any local adb server (adb kill-server) and avoid unpowered USB hubs.

Install the Google USB Driver (Android Bootloader Interface) via Windows Update Optional Updates or Device Manager before opening the WebUSB picker.

2. Enable OEM unlocking

  • On the Pixel, open Settings → About phone and tap Build number 7 times to enable Developer options.
  • Open Settings → System → Developer options and enable OEM unlocking and USB debugging.
  • Plug USB into this computer, then use Reboot to Fastboot below. This page talks WebUSB ADB and sends adb reboot bootloader (reboot:bootloader). The first time, unlock the phone and tap Allow USB debugging.
  • Manual fallback: hold Volume Down + Power, or run vendor/guardtalk/scripts/reboot-to-fastboot.sh on the USB host.
