1. Host check

  • Use a current Chromium, Chrome, Edge, or Brave window — not Firefox or Safari for live USB.
  • Private / Incognito windows are not a supported path. Origin storage in those windows is too small to hold the real artifacts.
  • On Linux, stop fwupd if it claims the fastboot device (systemctl stop fwupd.service).
  • Stock Android: enable OEM unlocking and USB debugging on the Pixel, plug USB into this computer, then use Reboot to Fastboot below. This page talks WebUSB ADB and sends adb reboot bootloader (reboot:bootloader). The first time, unlock the phone and tap Allow USB debugging. Stop a local adb daemon first (adb kill-server) or the browser cannot claim the USB interface.
  • Manual fallback: hold volume-down + power, or run vendor/guardtalk/scripts/reboot-to-fastboot.sh on the USB host. flash-from-remote.sh still auto-reboots when the phone is in Android.

    5–9. Connect, unlock, flash, lock

    Buttons call flashcore. Unlock is required before flash. Lock is rejected until the plan completes. Unlock and lock wipe user data when the Pixel accepts the command.

    Reconnect after reboot-bootloader

    When firmware or OS flashing reboots the bootloader, this page loses the USB session. Leave the Pixel in Fastboot Mode, then use Reconnect in the dialog. If you are installing from another phone, turn off desktop-site mode or the session will drop again.
