What this installer does not cover

Verified boot checks what your key signs. The items below stay outside that check. This page is static and makes no network request.

  • Firmware beneath AVB (baseband, boot ROM) is not signed by your key.
  • A signing machine already compromised can produce a valid signature on the wrong image.
  • A key copied without your knowledge is still a valid key.
  • The Gateway is a network-defence boundary for messages, not an absolute one.
  • This installer cannot detect coercion or a stolen backup passphrase.
