### 5.1 Falsification detail

**(a) `location_gnss_kernel` — 11/13 wrong (7× `A/B`, 4× `C/B`).**
The ledger §4.9 says "GNSS kernel drivers (`gnssif.ko`, `gnss_spi.ko`) are present in
`vendor_dlkm` but blocklisted → Tier B" on **all 13**. Re-derived from the shipped
`vendor_dlkm.img`:

- shiba, husky — present, in `modules.load`, `blocklist gnssif`/`gnss_spi` → **B (agrees)**.
- akita, tokay, caiman, komodo, comet, tegu, stallion — **modules absent** → **A**.
- frankel, blazer, mustang, rango — present, in `modules.load`, **not blocklisted** → **C**.

The cell is false **even against the exact artifact the ledger cites**: the built
`out/target/product/<dev>/vendor_dlkm/lib/modules/modules.blocklist` contains gnss
entries **only on shiba/husky** (`grep -cE 'blocklist (gnssif|gnss_spi)' … → 2`), and
`0` on the other 11 devices — so the cited path does not support the claimed Tier B
on 11/13 in either the `out/` tree or the shipped stamp.

**(b) `nitrous_module` — 4/13 wrong (`C/B`).**
The ledger §4.8 says the built `vendor_dlkm` blocklist "contains `blocklist nitrous`"
(Tier B) on all 13. The shipped stamps:

- shiba, husky, akita, tokay, caiman, komodo, comet, tegu, stallion — `blocklist nitrous`
  present → **B (agrees)**.
- frankel, blazer, mustang, rango — `nitrous.ko` in `modules.load`, **0 `nitrous`
  blocklist lines** (stock blocklist) → **C**.

This independently **confirms Architect pre-finding `E-10`** and falsifies the
ledger's blanket B.

**(c) `nfc_userspace_hal` — 1/13 wrong (`B/A`).**
The ledger §4.10 + the rango cell ("built vendor installed-files manifest contains 0
NFC HAL entries", Tier A) is contradicted by its **own cited artifact**:
`out/target/product/rango/installed-files-vendor.txt` lines 1602 and 1678 are
`/vendor/overlay/NfcOverlayRangoGsi.apk` (8542 B) and `/vendor/etc/libnfc-hal-st_evt.conf`
(6539 B); `debugfs -R 'stat …'` on `releases/desktop-flash/rango-latest/vendor.img`
shows both in the **shipped** vendor image. No NFC HAL service binary was found, so
the correct tier is **B**, not A. New finding (not in `E-1`…`E-16`).
