### 3.3 Wi‑Fi / BT kernel modules (blocklist + BT excision)

| Item | akita (zuma / akita-kernels) | tokay (zumapro / caimito-kernels) |
|------|------------------------------|-----------------------------------|
| Wi‑Fi driver | `bcmdhd4383` | `bcmdhd4390` |
| Upstream blocklist Wi‑Fi entry | `blocklist bcmdhd4383` | `blocklist bcmdhd4390` |
| Device insmod re-load | `init.insmod.akita.cfg` → `modprobe\|bcmdhd4383.ko` | `init.insmod.tokay.cfg` → `modprobe\|bcmdhd4390.ko` |
| BT power/rfkill | `nitrous.ko` present in `vendor_dlkm.modules.load` | same (`nitrous.ko`) |
| Touch blocklist entry | `goodix_brl_touch` | `sec_touch` / `syna_touch` (caimito set) |

GuardTalk shared BT override today:

```make
BOARD_VENDOR_KERNEL_MODULES_BLOCKLIST_FILE := vendor/guardtalk/feature-excised/vendor_dlkm.modules.blocklist
```

That file is a **caimito/zumapro (tokay) mirror + `blocklist nitrous`**. It is **not** a drop-in for akita:

- Uses `bcmdhd4390` (wrong Wi‑Fi module name for akita → must use `bcmdhd4383` baseline).
- Omits akita upstream `goodix_brl_touch`.
- Adds caimito-only panel/test entries (`gs-panel-common-test.ko`, `panel-gs-tk4c-test.ko`, `sec_touch`, etc.) that are not on the akita upstream blocklist.

**LAYER action:** either a zuma-specific GuardTalk blocklist (recommended) mirrored from
`device/google/akita-kernels/6.1/grapheneos/vendor_dlkm.modules.blocklist` **plus** `blocklist nitrous`, or a parameterized SoC variant. Do **not** point akita at the current tokay shared file without reconciling.
